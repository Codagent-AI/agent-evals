Add an agent skill to this repo that turns a topic into a browser-based presentation. Instead of a deck of separate slides, a presentation is one diagram that evolves through a sequence of steps: elements appear, move, connect, and get relabeled as the explanation develops, and each step has its own caption. Viewers should be able to move through the steps, switch between presenting it and browsing it, and see it look right at different screen sizes. The skill should build on reusable scene components, work even in a project that doesn't have them set up yet, and check that what it generates actually builds and renders. Use the skill to make a sample presentation that explains how to use the skill itself, and give us a way to verify presentations automatically.
